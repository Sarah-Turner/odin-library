# odin-library
I made this website to practice using JavaScript constructors and DOM manipulation. This project also helped me practice using forms to extract information from the user and display that information in a table. Currently, the library does not have persistent storage and will be wiped after reloading the page. The form also has some basic client side validation to ensure the user enters a valid book.
